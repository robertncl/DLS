The ACME brand wordmark — Signal Red mark with an upright white "A", then ACME in Inter 700 uppercase; use in top bars, footers, and auth screens.

```jsx
<Wordmark href="/" />
<Wordmark onDark />    // on dark grounds (Graphite 900/950), 20px+
<Wordmark markOnly />  // mark alone, 24px+ only
```

Set font-size via style to scale it. On dark grounds (Graphite 900/950 bands, dark slides) use `onDark` at 20px+ (white letters; the mark lifts to red-500 so it stays a bright 3:1+ shape) — never hand-set a colour. Don't italicise the "A", swap the face, or place the mark on a red or other saturated ground.
