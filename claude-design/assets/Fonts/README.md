# Fonts

The font files in `fonts/` are open-licensed under the SIL Open Font License 1.1 (the licence texts are in this folder):

- **Inter** (sans and headings; 400, 500, 600, 700) is the single brand family, as in the source repo (v5). `--acme-font-display` aliases the sans stack.
- **JetBrains Mono** (mono; 400, 600) is the brand's mono face for code, SKUs and identifiers, self-hosted here; the source names it in its stack but ships no file.

The v4 serif display face (Tiempos Headline, with Source Serif 4 as its stand-in) and Styrene B were retired with the v5 sync, and their files removed. Files are Latin subsets.
